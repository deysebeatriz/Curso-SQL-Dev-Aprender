# Curso SQL - Dev Aprender

Repositório dedicado aos meus estudos e resolução de desafios do [Curso SQL Completo para Iniciantes](https://www.youtube.com/watch?v=G7bMwefn8RQ) ministrado pelo canal **Dev Aprender** (Jhonatan de Souza).

## Sobre o Projeto
Este projeto funciona como um portfólio do meu aprendizado prático em Banco de Dados. Aqui estão documentados os scripts SQL contendo os comandos que estudei, consultas complexas e a resolução de problemas de negócios fictícios propostos durante as aulas.

## Base de Dados
Os scripts deste repositório foram desenvolvidos utilizando o banco de dados de exemplo **AdventureWorks2017**.
O mesmo pode ser baixado neste [link](https://drive.google.com/file/d/1LCofjYj-pV1asBLrxtgPDsbqMFRefHW5/view)

## Tópicos Abordados
Durante o curso, pratiquei e apliquei os seguintes conceitos de SQL Server:

*   **Consultas Básicas:** `SELECT`, `DISTINCT`, `TOP`
*   **Filtros e Operadores:** `WHERE`, `AND/OR`, `BETWEEN`, `IN`, `LIKE`
*   **Ordenação e Agrupamento:** `ORDER BY`, `GROUP BY`, `HAVING`
*   **Funções de Agregação:** `COUNT`, `SUM`, `MIN`, `MAX`, `AVG`
*   **Relacionamentos (Joins):** `INNER JOIN`, `LEFT/RIGHT/FULL OUTER JOIN`, `SELF JOIN`, `UNION`
*   **Consultas Avançadas:** Subqueries (Subselects)
*   **Manipulação de Dados:** Funções de Data (`DATEPART`), String e Funções Matemáticas
*   **Estrutura e CRUD:** `CREATE TABLE`, `INSERT`, `UPDATE`, `DELETE`, `ALTER TABLE`, `DROP TABLE`
*   **Outros:** Chaves Primárias (PK), Chaves Estrangeiras (FK), Restrições (`NOT NULL`, `UNIQUE`, `CHECK`) e Views.
